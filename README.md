# Nutrition and Training Analytics

Учебное приложение на Python для анализа данных о питании и тренировках.

Проект разрабатывался в команде. Приложение позволяет загружать данные, редактировать их, проводить базовый анализ и формировать отчёты.

## Основные возможности

- загрузка данных из Excel
- обработка и хранение данных
- редактирование пользовательской информации
- анализ данных о питании и тренировках
- построение графиков
- формирование отчётов
- экспорт результатов в Excel
- работа через графический интерфейс

## Технологии

- Python
- Pandas
- Matplotlib
- OpenPyXL
- Tkinter
- Excel

## Запуск проекта

Для запуска необходимо установить Python и зависимости проекта.

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Запуск приложения:

```bash
python gui_sports.py
```
